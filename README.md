# Fulvio

https://fulvio.vercel.app

Esta web ayuda a quienes buscan mejorar su tenis a conocer las clases y contactar con Fulvio, coach en Phuket, Tailandia. Con amplia experiencia enseñando a una clientela exigente en Tailandia e Italia, ofrece un servicio premium basado en el método español que aprendió de su amigo Rafa Nadal.

## Puesta en marcha

```bash
pnpm install
pnpm dev
```
